# osw-frontend

> Frontend for OSWatcher project

## Requirements

- `Python >= 3.7`
- `NodeJS`

## Setup

Backend

    virtualenv -p python3 venv
    source venv/bin/activate
    (venv) pip install -r requirements.txt

Frontend

    cd frontend
    npm install

##  Usage

Backend

    (venv) ./run.py

Frontend

    cd frontend
    npm run serve
